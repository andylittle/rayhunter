# Alcatel LinkZone MW41MP

The Alcatel LinkZone MW41MP (MetroPCS SKU, built by TCL) is a Qualcomm
MDM9207-based mobile hotspot available used for roughly $10-20. It has no
screen. It does have status LEDs, but the stock firmware actively repaints
all of them (signal, battery, SMS, WiFi) every second or so to reflect real
device status, reverting any value Rayhunter writes within a few seconds.
Rayhunter currently runs headless on this device (no LED indicator) as a
result; this may be revisited if a way to disable that behavior turns up.

**Automated installation is not yet available.** This page currently covers
manual installation only; an `./installer` subcommand is planned as a
follow-up.

## Supported bands

Refer to the device's FCC ID for the exact band list for your unit.

## Hardware

- SoC: Qualcomm MDM9207 (Cortex-A7, armv7)
- 256 MB NAND, split into a small root filesystem and a `/cache` partition
- microSD slot (varies by unit; not present on all SKUs)
- No display; status LEDs only

## Obtaining a shell

The MW41MP enumerates over USB as a mass-storage device. A documented
vendor SCSI command (public since 2021, used by TCL's own factory service
tool) switches it into a debug mode that starts `adbd` as root:

```sh
sudo sg_raw -v /dev/sgX 16 f9 00 00 00 00 00 00 00 00 00 00 00 00 00 00
adb shell
```

Replace `/dev/sgX` with the `sg` device corresponding to the MW41MP's
mass-storage function (check `lsusb` and `ls -l /dev/sg*` to identify it).
This requires root on the host to send the SCSI command. Debug mode does
not persist across a reboot; the command needs to be sent again each time.

## Installing manually

Rayhunter has no dedicated storage partition on this device; the root
filesystem has only a few MB free. Install the daemon and config to
`/cache/rayhunter/` instead, and if your unit has a working microSD slot,
point `qmdl_store_path` in `config.toml` at the card (it mounts
automatically at `/media/card`) rather than at `/cache`, since `/cache` only
has tens of MB free.

See [Installing Rayhunter manually](./porting.md#installing-rayhunter-manually)
for the general steps (pushing the daemon binary and config, and setting up
the init script). Use `device = "mw41"` in `config.toml`.

## LED modes

Not currently supported; see the note above. Check the web UI (port 8080)
for recording status instead.

## Developing

`/dev/diag` on this device is already shared concurrently by several stock
processes, so no vendor daemon needs to be stopped to use it.
